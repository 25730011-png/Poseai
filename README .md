## 0. 폴더 구조

화면은 `index.html` 하나에 section으로 나눠 넣고 주소 끝 `#이름`으로 전환하며, 기능은 모두 `js/app.js`에 있습니다.

```
index.html                 화면 구조 (홈·측정·리포트·기록·가이드·공부 타이머·FAQ·설정·로그인)
README.md                  이 문서 (변경 이력 · 기획 정리 · 주차별 작업 내용)
css/style.css              디자인 (Figma 기준, 그린 테마)
js/app.js                  측정 · 기록 · 그래프 · 가이드 · 공부 타이머 · FAQ·AI 코치 · 설정 · 로그인
data/                      앱이 읽는 JSON 6개
  criteria.json            참고 범위 기준표 + 출처
  guide.json               스트레칭 7개 (공식 자료·영상 연결)
  body-parts.json          불편한 부위별 안내
  combos.json              같이 나타난 자세 패턴
  faq.json                 자주 묻는 질문
  hospital-codes.json      병원 찾기 지역·진료과목 코드
pages/
  asset/logo.svg           로고
  asset/icons/             화면에 쓰는 선 아이콘 (svg)
  asset/images/            스트레칭 동작 그림, 포즈봇(coach-bot.png), 공부 타이머 그림
  firebase-rules.txt       Firestore 보안 규칙 (본인만 읽기·쓰기)
```

## 1. 기획 정리 (v0.5)

기획서(v0.1)에서 시작해서 지금(v0.5)까지 구현된 내용을 정리한 문서입니다.

### 1.1 문제 정의와 가치 제안

- **문제 정의**: 공부·과제로 오래 앉아 있는 대학생은 거북목·어깨·골반이 서서히 틀어져도 거울이나 사진으로는 알기 어렵고, 병원 검사나 교정 기기는 비용·예약 부담이 있어 그냥 넘어간다.
- **가치 제안**: 설치·가입·장비 없이 카메라 앞에 서기만 하면 3가지 체형 경향을 재 주고, 결과에 맞는 스트레칭과 공부 중 자세 알림까지 이어서 꾸준히 관리하게 돕는다.
- **근거 자료 (2026년 발표 자료만 사용)**: 거북목증후군 진료인원 254만 명(2024), 관련 진료비 2,864억 원(2020) → 6,095억 원(2025)으로 약 2.1배 (건강보험심사평가원 국민관심질병통계, 2026.5 보도 · 2026.7 분석)

**진단 · 교정 · 예방 3단계**

| 단계 | 기능 | 주기 |
|---|---|---|
| 진단 | 체형 측정 (서서 정면·측면 5초씩) | 1~2주에 한 번 |
| 교정 | 결과에 맞춘 스트레칭 + 스트레칭 달력 | 매일 |
| 예방 | 공부 타이머 (앉아 있는 동안 목이 나오면 알림) | 공부할 때 |

### 1.4 MVP 범위

**기획서 MVP (v0.1)**
노트북 웹캠으로 거북목·어깨 수평·골반 수평 3가지를 측정해 양호/주의/확인 권장과 종합 점수로 보여 주고, 날짜별 기록과 교정 가이드까지 이어 주는 웹서비스.

**지금 MVP (v0.5)**
휴대폰이나 노트북 카메라 앞에 서면 정면·측면을 5초씩 자동으로 재서, 점수 대신 지금 상태와 지난번 대비 변화를 알려 주고, 결과에 맞는 스트레칭(매일)과 공부 중 자세 알림까지 이어 주는 모바일 웹서비스. 세 가지 기록은 내 기록 화면에 모인다.

**MVP 완료 조건**

| 기능 | 완료 조건 | v0.5 충족 |
|---|---|---|
| 자동 측정 | 사람이 보이면 버튼 없이 정면 → 측면 순서로 측정된다 | 충족 |
| 상태 안내 | 3가지 항목마다 각도·방향·상태가 보인다 | 충족 |
| 기록 | 저장한 기록이 날짜별로 쌓이고 그래프로 보인다 | 충족 |
| 교정 가이드 | 결과에 맞는 스트레칭만 골라서 보여 준다 | 충족 |
| 모바일 | 휴대폰 화면에서 잘림 없이 쓸 수 있다 | 충족 |

### 1.6 사이트맵

하단 탭 4개: **홈 · 측정 · 기록 · 가이드**. 상단 왼쪽 메뉴(≡)에서 모든 화면으로 가고, 포즈봇 버튼은 모든 화면에 떠 있습니다.

```
PoseAi
├─ [탭] 홈 ─→ 측정 시작 · 공부 타이머 · 최근 리포트
├─ [탭] 측정 ─→ 체형 리포트 ─→ 기록 저장
├─ [탭] 기록 (변화 그래프 · 스트레칭 달력 · 공부 중 자세 · 날짜별 기록)
├─ [탭] 가이드 (불편한 부위 · 맞춤 스트레칭 · 병원 찾기)
├─ [메뉴] 공부 타이머 · FAQ·AI 자세 코치 · 설정
├─ [떠 있는 버튼] 포즈봇 대화창
└─ [상단] 로그인 (─→ 회원가입)
```

| 주소 | 화면 | 내용 |
|---|---|---|
| `#home` | 홈 | 서비스 소개, 진행 순서, 측정 항목, 공부 타이머 바로가기, 다음 측정 D-day |
| `#measure` | 측정 | 정면·측면 각 5초 자동 측정 |
| `#report` | 체형 리포트 | 오늘의 자세 요약, 항목별 각도·상태, 지난번 대비 변화, 같이 나타난 자세 패턴, 기록 저장 |

### 1.7 User Flow

**흐름 A — 진단 (처음 재 보기)**
시작: 홈, 기록 없음 / 완료: 리포트를 보고 기록 저장

| 단계 | 행동 | 결과 | 화면 |
|---|---|---|---|
| 1 | 「측정 시작하기」 | 카메라가 켜지고 서는 위치 안내 | 홈 → 측정 |
| 2 | 카메라 앞에 정면으로 서기 | 사람이 보이면 5초 준비 후 정면 5초 측정 | 측정 |
| 3 | 옆으로 돌아서기 | 측면 5초 측정 | 측정 |
| 4 | 결과 확인 | 오늘의 자세 요약, 항목별 상태 | 리포트 |

| 1 | 가이드에서 불편한 부위 선택 또는 측정 결과로 자동 추천 | 맞춤 스트레칭만 보임 | 가이드 |
| 2 | 동작 그림·영상 보고 따라 하기 | | 가이드 |
| 3 | 「오늘 했어요」 | 스트레칭 달력에 표시 | 가이드 → 기록 |

**흐름 C — 예방 (공부하면서)**

| 단계 | 행동 | 결과 | 화면 |
|---|---|---|---|
| 1 | 공부 시간(25분/50분) 고르고 시작 | 처음 3초 동안 바른 자세 기억 | 공부 타이머 |

### 1.9 측정 기준 (`data/criteria.json`)

| 항목 | 보는 방향 | 참고 범위 | 조금 벗어남 | 많이 벗어남 | 화면에 보이는 상태 |
|---|---|---|---|---|---|
| 거북목 | 측면 | 10° 미만 | 10~20° | 20° 이상 | 바른 편 / 앞으로 나온 편 / 많이 나온 편 |
| 어깨 수평 | 정면 | 3° 미만 | 3~5° | 5° 이상 | 거의 수평 / 조금 기운 편 / 많이 기운 편 |
| 골반 수평 | 정면 | 3° 미만 | 3~6° | 6° 이상 | 거의 수평 / 조금 기운 편 / 많이 기운 편 |

- 거북목은 RULA 목 굽힘 구간, 어깨·골반은 사진 측정 연구와 골반 경사 정상 범위를 참고했습니다. 출처는 파일 안에 함께 적었습니다.
- 예: 어깨 높이 차 0.02, 가로 거리 0.24 → atan(0.02÷0.24) ≈ 4.8° → 조금 기운 편
- 웹캠은 엑스레이와 재는 방법이 달라서 정의가 완전히 같지는 않습니다. 그래서 진단이 아닌 참고용으로 안내합니다.

### 3.3 사용 원칙

- **기준값은 연구 출처와 함께**: 판단 기준은 코드가 아니라 `criteria.json`에 출처와 같이 두고, 진단이 아닌 참고용으로 안내합니다.
- **공식 자료로 확인**: 스트레칭은 AI 초안을 공식 기관 자료로 확인하고, 화면에 출처를 적습니다.
- **통계는 2026년 공식 발표만**: 발표·영상 자료에는 2026년에 나온 자료만 씁니다.
- **개인정보**: 영상·사진은 저장·전송하지 않고, AI 코치에는 질문과 측정 수치만 보냅니다.
- **키 관리**: API 키는 Cloudflare 중계 서버에만 두고 코드·채팅에 적지 않습니다.

## 5. 실행과 검사

### 실행

이 폴더에서 VS Code Live Server 또는 `python -m http.server 8000` → `http://localhost:8000`. HTML을 더블클릭(file://)하면 브라우저가 JSON fetch를 막습니다. 카메라는 https 주소나 localhost에서만 켜집니다. 배포는 GitHub Pages.

### 설정

- Cloudflare 중계 서버(`poseai-relay`): 설정 → 변수 및 비밀에 Gemini 키와 심평원 오픈API 키
- Firebase: `js/app.js`의 Firebase 설정값, Firestore 규칙은 `pages/firebase-rules.txt`를 콘솔 규칙 탭에 붙여넣기
- 파일을 고치면 `index.html`의 `style.css?v=` · `app.js?v=` 숫자를 올려서 브라우저 캐시를 피합니다. (지금 v=96 · v=98)

### 디자인 기준

- 색: 바탕 세이지·크림, 진한 초록 `#24603F`, 주황 포인트 `#E2683A`
- 글꼴: Poppins(영문·숫자), Noto Sans KR(한글)
- 모바일 전용 화면, 하단 탭 4개, 포즈봇 버튼은 끌어서 옮길 수 있음
- 동작 그림 배경은 연두색, 파란색 쓰지 않음
